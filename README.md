# Generador de Hashes PBKDF2-SHA256

Este proyecto proporciona una herramienta simple para generar un hash seguro de una contraseña utilizando el algoritmo **PBKDF2-SHA256**. Este algoritmo es ampliamente utilizado para la protección de contraseñas y es el mismo que usa Django para el almacenamiento de contraseñas.

- Python 3.x
